# Audit Phase 1 - MVP local

## Résultat du premier audit

Statut : en cours.

## Corrections effectuées

- Le bouton `Suivre` de la boutique change maintenant d'état.
- Le bouton `Trier` alterne entre tri par défaut, prix croissant et prix décroissant.
- Le bouton `Plus tard` de l'espace vendeur est remplacé par un retour clair vers l'accueil.
- Le bouton `Appeler` du suivi ouvre le téléphone du livreur.
- Le bouton `Appeler` est désactivé quand le numéro du livreur n'est pas affiché publiquement.
- Le libellé `description vocale` est remplacé par une action utile : ajouter une précision de livraison.
- Le libellé `Publication démo locale` est remplacé par `Publication boutique`.

## Parcours vérifiés

- Parcours achat complet depuis la boutique.
- Modification de livraison avant paiement.
- Création commande et apparition dans le suivi.
- Notation livreur après commande.
- Ajout produit vendeur.
- Passage produit disponible / vendu.
- Ajout et retrait livreur dans les réglages.
- Changement de couleur dans les réglages.

## Décision

La phase 1 locale est validée. La publication reste bloquée.
