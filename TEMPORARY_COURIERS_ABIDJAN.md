# Liste temporaire de livreurs - Abidjan

Cette liste est conservée temporairement pour proposer des options de livraison aux acheteurs Yapalaan.

Les frais affichés dans l'application sont des estimations internes. Ils pourront être remplacés plus tard par :

- des tarifs négociés avec les prestataires ;
- une commission Yapalaan sur chaque livraison ;
- une disponibilité réelle par zone ;
- une intégration partenaire ou Supabase.
