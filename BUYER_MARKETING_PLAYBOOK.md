# Playbook marketing acheteurs - Yapalaan

## Positionnement

Yapalaan n'est pas seulement un catalogue. C'est un achat local plus sur.

## Message principal

> Achetez local sans peur.

## Message secondaire Import

> Importez depuis la Chine avec un prix clair en FCFA.

## Angles de contenu

- Produit disponible maintenant.
- Prix clair.
- Livraison avec cout visible.
- Vendeur controle.
- Paiement protege.
- Litige possible si probleme.
- Score confiance vendeur.
- Devis import transparent.

## Canaux prioritaires

1. WhatsApp status.
2. TikTok.
3. Instagram Reels.
4. Facebook groupes.
5. Micro-influenceurs Abidjan.

## Campagne de lancement

Nom : Yapalaan Securite Marche

Offres :

- Livraison reduite sur les 100 premieres commandes.
- Verification gratuite pour les 50 premiers vendeurs.
- Reduction acheteur apres recommandation.
- Mise en avant gratuite des premiers vendeurs fiables.
