# Plan monetisation et leadership - Yapalaan

Date : 2026-06-07

## Positionnement gagnant

Yapalaan ne doit pas essayer d'etre "un autre Jumia".

Yapalaan doit devenir :

> La couche de confiance au-dessus du commerce WhatsApp, avec achat local, livraison suivie et import Chine assiste.

## Pourquoi ce positionnement est fort

- Les vendeurs utilisent deja WhatsApp, Instagram, TikTok et Facebook.
- Les acheteurs veulent acheter vite, mais ont peur des arnaques.
- Les importateurs veulent les prix Chine, mais craignent douane, langue, delais et fournisseurs.
- Yapalaan peut monetiser la confiance, pas seulement le catalogue.

## Piliers monetisables

### 1. Commission vente locale

Phase pilote :

- 5% par vente reussie.

Phase croissance :

- 7% a 10% selon categorie et niveau vendeur.

Regle :

- Pas de commission sur commande echouee.
- Commission seulement apres livraison confirmee ou paiement valide.

### 2. Commission livraison

Fourchette :

- 300 a 1 000 FCFA par livraison.

Pourquoi :

- Yapalaan apporte le client, le suivi, le choix livreur et la preuve de livraison.

### 3. Service "Acheter pour moi" - Chine

Mode MVP :

- 10% du cout produit.
- Minimum : 5 000 FCFA.

Peut augmenter selon complexite :

- achat simple : 10% ;
- recherche fournisseur : 12% ;
- verification fournisseur / negotiation : 15% ;
- commande groupee : marge sur consolidation.

### 4. Commandes groupees Chine

Yapalaan gagne sur :

- consolidation ;
- frais de service ;
- marge logistique ;
- reduction des couts partagee avec le client.

### 5. Services vendeurs

A lancer apres preuves de ventes :

- Pack photo produit : 5 000 a 25 000 FCFA.
- Creation fiche produit : 2 000 a 10 000 FCFA.
- Mise en avant produit : tarif journalier ou hebdomadaire.
- Badge vendeur Premium : abonnement plus tard.

### 6. Mise en avant produit

A ne pas lancer trop tot.

Conditions :

- vendeur verifie ;
- produit disponible ;
- note vendeur suffisante ;
- historique litige acceptable.

## Fonctionnalites a ajouter pour etre parmi les meilleurs

### Score confiance

Score visible base sur :

- telephone verifie ;
- WhatsApp verifie ;
- geolocalisation ;
- piece ou controle manuel ;
- avis ;
- commandes reussies ;
- litiges.

### Protection achat claire

Texte standard :

> Votre achat est suivi. En cas de probleme, Yapalaan peut ouvrir un litige et verifier vendeur, livreur et produit.

### Parcours sans compte acheteur

Garder :

- achat rapide sans compte ;
- creation de compte apres commande ;
- recherche commande par telephone + code.

### Compte vendeur obligatoire

Obligatoire avant publication produit :

- telephone/OTP ;
- WhatsApp ;
- geolocalisation ;
- acceptation conditions vendeur.

## Priorite d'execution

1. Deployer Edge Function checkout.
2. Brancher paiement test Mobile Money.
3. Connecter demandes import a Supabase.
4. Ajouter auth vendeur.
5. Ajouter score confiance reel.
6. Lancer 20 commandes pilotes.
7. Recruter 50 vendeurs.
8. Commencer marketing payant.

## Metriques de leadership

Yapalaan devient credible quand :

- 100 commandes reussies ;
- 90% livraisons reussies ;
- moins de 5% litiges ;
- 30 acheteurs repetent ;
- 50 vendeurs verifies ;
- 10 vendeurs vendent au moins 3 fois ;
- 20 devis import traites ;
- 5 commandes import payees.

## Regle strategique

Ne pas vendre "beaucoup de produits". Vendre "moins de peur".

La confiance est la marque. Le catalogue vient apres.
